# Controller artwork

- `controller.eps`：用户提供的 Xbox-layout 原始素材，文件名来源为 `vecteezy_joystick-icon-vector_29890064_318`。
- `controller.pdf`：从 EPS 内的 PostScript 矢量内容生成，供 AppKit 运行时使用。
- `controller.svg`：早期备用素材，来自 Wikimedia Commons，许可见 `LICENSE-controller.txt`。

运行时锚点以 PDF 中彩色按钮的实际中心为准：Y `(0.7481, 0.7778)`、B `(0.8111, 0.6833)`、A `(0.7463, 0.5833)`，坐标原点为素材左下角。
