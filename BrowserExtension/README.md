# sui Chromium Extension

开发阶段在 `chrome://extensions` 开启 Developer mode，选择 **Load unpacked**，并指向这个文件夹。固定 extension ID 为 `khknllalpdcffgcpcmhmlbfllabepigc`。

macOS App 启动时会为 Chrome、Chromium、Edge 和 Brave 写入 Native Messaging Host 描述。正式发布需要把同一扩展作为 Chrome Web Store Unlisted 项目发布，才能使用 macOS External Extensions 伴随安装；浏览器仍会要求用户确认 Enable。
