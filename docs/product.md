# sui V0.1 产品规格

## 一句话

sui 是一个 macOS 菜单栏 Push-to-Talk 自动化工具：按住已绑定的手柄按键说话，松开后把本地转写文本发送到当前 Telegram 聊天、X.com 新 Post 或当前 Codex 会话。

## 固定交互

| 按键 | 默认插件 | 行为 |
| --- | --- | --- |
| A | Telegram | 按住录音，松开发送到当前聊天 |
| B | X.com | 按住录音，松开后由浏览器扩展发布 |
| Y | Codex | 按住录音，松开发送到当前会话 |

- 一次只接受第一个已绑定按键；录音中按其他键不切换目标。
- 插件在按下时检查目标是否就绪，同时开始录音，避免吞掉开头。
- 目标不就绪时丢弃录音，把 sui 拉到前台并显示具体修复动作。
- 不处理与 Steam、游戏或其他软件的按键冲突。

## 就绪规则

| 插件 | 可用 | 就绪 | 执行 |
| --- | --- | --- | --- |
| Telegram | Telegram 已安装 | 正在运行且当前窗口存在可编辑消息框 | 聚焦、粘贴、Return |
| X.com | Chromium/Safari 扩展可用 | 扩展能打开 X compose 且已登录 | DOM 填入并点击 Post |
| Codex | Codex/ChatGPT 已安装 | 当前页面存在可编辑 prompt | 聚焦、粘贴、Return |

## 唯一窗口

默认页是一张手柄映射图。A/B/Y 的连线直接连接三个下拉菜单。插件不可用时仍显示但置灰。

右上角设置按钮在同一个窗口中切换到设置页，只包含：

1. 当前手柄选择。
2. 已安装插件列表及 Enable 开关。

平常关闭窗口后只留菜单栏图标。错误不用通知中心；窗口直接到前台。

## 明确不做

- 不替用户选择 Telegram 聊天、X 账号或 Codex task。
- 不做通用输入法、历史记录、云同步或账号系统。
- 不持有第三方凭据。
- 不保证任意网页结构、任意 App 或任意手柄。
- 不在 V0.1 提供任意代码执行式社区插件；插件协议保持可扩展，社区插件审核后随版本编译。
